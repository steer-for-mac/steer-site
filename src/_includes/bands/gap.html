Your Mac can remap a controller. It cannot be run by one.

macOS has a Game Controllers pane, and it does one job: swap a button for another button, inside games. Nothing in it points, types, or opens an app.

macOS on its own
  • One button becomes another button
  • Inside games only
  • Light bar colour
  • Haptics on or off
With Steer
  • Point and click anywhere
  • Type without a keyboard
  • Open any app
  • Arrange windows

Checked in System Settings › Game Controllers. If Apple adds more, this page will say so.
