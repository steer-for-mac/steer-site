Changelog

What changed in each version of Steer. Betas come before each release, for anyone who turns on “Receive beta updates” in Settings → Steer → About.

Releases

None yet: 1.0 is still to come. The betas below are what Steer ships today, and a purchase includes every one of them.

Betas

Download the current beta, {{ beta.version }}. It updates itself to each newer one.

1.0b4 November 3, 2026

  • Shortcuts work on French and German keyboards. Steer’s built-in shortcuts now mean the letter, not where that letter sits on a US keyboard. Before, on a French keyboard select all (L1+R1+✕) sent ⌘Q and quit the app, and undo sent ⌘W. Shortcuts you recorded yourself were already right and are unchanged.
  • You see a setup file before it changes anything. Opening a .steercustomization file now shows what it changes, what each button did before, and anything Steer couldn’t read. Nothing changes until you choose Import, and a version is saved first.
  • A setup file only changes the buttons it names. Before, importing a file that set one button left every other button in that app doing nothing.
  • For AI agents and scripts: steer://propose sends Steer a change to review, and steer://query/…?to=file reads state back to a file instead of your clipboard.

1.0b3 November 3, 2026

  • Teach your controller can email what it found. If Steer doesn’t know your pad, the last step now drafts an email with its name and IDs attached, instead of a GitHub issue nobody could file.
  • Suggest an idea works. It used to open a page that didn’t exist; it now opens an email to me.
  • Sentence mode on the left stick can fire the same cell twice in a row. Before, it ignored the second push.
  • Restoring macros from History no longer leaves two macros with the same name, including names that differ only in capitals.
  • More off-brand pads in the beta list, including GameSir and SteelSeries models, from the latest community mappings. Still untested on real hardware.

1.0b2 October 31, 2026

No changes from 1.0b1. This beta exists to check that an installed beta finds the next one and updates itself, before anyone depends on it.

1.0b1 October 30, 2026

The first beta. Steer turns a game controller into your Mac’s mouse and keyboard, and everything on the features page is in it.

  • Free while it’s the newest beta. A beta needs no licence until three days after the next one is out, and for 45 days at most. After that it falls back to the free trial, with none of its days spent.
  • Updates arrive on their own. Beta builds start with “Receive beta updates” on: Steer checks about once a day and installs the next beta when you quit it. Turn it off in Settings → Steer → About.
  • Tell me what breaks. Report a Problem in Steer Help drafts an email with diagnostics attached, and nothing is sent until you send it.

Known gaps: translations are machine-generated and unreviewed, and a DualSense Edge’s rear paddles are untested.
