# SEO audit, 2026-11-04

Live site, steer.seanfloyd.dev, GitHub Pages, built by Eleventy into static HTML.
Checked with curl against production, `dist/` from `make build`, and Lighthouse 12
(SEO category) against the local nginx copy.

Short version: nothing blocks crawling. The site was invisible because nothing
told search engines it exists and nothing links to it, not because of a fault on
the page. Whether Google or Bing have indexed it is **unverified** (see 2).
